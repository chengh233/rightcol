# 行业结构分析

先读 `FRAMEWORK.md`（判断标准的唯一来源），本文件只讲流程。

## 第一步：确定同业样本 —— 这一步决定成败

```bash
python bin/sector.py --group <组名>        # 横切数据 → data/sector_<组名>.md
                                           # 组定义见 sectors/groups.yml
python bin/sector.py TICK1 TICK2 TICK3     # 或直接给列表
```

⚠️ **选错同行，整张对标表都是错的参照系。** 分组标准不是 GICS 行业分类，
而是「**赚钱的方式是否可比**」：

- 苹果和微软同属"科技"，但一个卖硬件（毛利 47%）一个卖软件（毛利 70%），
  直接比毛利率毫无意义。
- Costco 和 Walmart 可比；Costco 和亚马逊不可比（会员制零售 vs 平台+云）。

**宁可分得细、样本小（≥3 家），也不要为了凑样本把商业模式不同的公司塞进来。**
如果用户给的组合明显不可比，**直接指出来并建议拆分**，不要硬做。

## 第二步：读横切表

**判读规则：不看绝对值，看分位数。** 表里每个数后面括号里就是分位数（0~100，
已按指标方向校正）。

关键动作：**找出"分位数在下行"的公司** —— 一个从 80th 掉到 55th 的高毛利公司，
比一个从 30th 升到 60th 的低毛利公司危险得多。前者护城河在漏水。

（当前版本只给最新财年的截面。要看分位数的移动方向，需对多个年份分别跑，
或手工对比数据包。这是已知缺口，见 `FRAMEWORK.md` §13 路线图。）

## 第三步：回答行业结构的六个问题

1. **这门生意的经济结构是什么？**
   钱从哪来、成本结构、资本强度（资本开支/营收）、周期性、进入壁垒。
2. **价值在产业链的哪一环沉淀？**
   谁有定价权？**上下游账期就是话语权的账面证据**——看 CCC 和 DPO：
   谁在无息占用别人的资金，谁在被占用。
3. **行业处于生命周期的哪一段？**
   渗透率、增速、集中度在提升还是分散。不同阶段该看的指标和该给的估值完全不同。
4. **供给侧在发生什么？**
   对周期性行业，**供给比需求更可预测、也更决定回报**。看全行业资本开支强度：
   集体扩产 = 未来两三年价格战。
5. **份额在往谁那里流？**
   营收增速的分位数差异，就是份额转移的财务显影。
6. **这个行业里，什么样的公司注定赚不到钱？**
   （比"谁最好"更有用——它直接定义了 Stop Doing List。）

## 第四步：识别该行业的特有指标

通用指标在某些行业会失效，必须补该行业的专用指标。举例：

| 行业 | 通用指标失效在哪 | 该看什么 |
|---|---|---|
| 软件/SaaS | 高毛利掩盖获客成本 | NDR、Rule of 40、CAC 回收期、SBC/FCF |
| 半导体 | 强周期使当期 PE 失真 | 产能利用率、库存周天、资本开支周期 |
| 银行/保险 | **没有毛利/存货/资本开支** | NIM、拨备覆盖、资本充足率、综合成本率 |
| 零售 | 合并数字掩盖店效 | 同店销售、坪效、会员续费率 |
| 能源 | 盈利随商品价格摆动 | 储量替代率、盈亏平衡油价、正常化盈利 |
| 生物医药 | 当期利润与价值无关 | 管线阶段、专利悬崖时间表 |

**如果对标表里大量 `—`，先判断这是"数据缺失"还是"结构上不适用"**——
数据包和横切表的失败区会区分这两者。金融机构属于后者。

## 第五步：输出

写入 `sectors/<组名>.md`（**认知档案**，与 `data/sector_<组名>.md` 那份机器产物
严格分开——后者可随时重跑覆盖，前者是不可再生的资产）。必须包含：

- **这门生意的经济结构**（一段话讲清楚钱怎么赚）
- **谁在赢、凭什么**（用分位数支撑，不用印象）
- **谁注定赚不到钱**（以及为什么）
- **行业级的翻转条件**：什么变化会让整个行业的判断改变
  （通常是供给、技术路线、监管、或替代品）
- **值得进一步单独分析的候选**（然后用 `/dossier` 逐个过三闸门）

## 输出纪律

- 不给买卖建议，不排"最值得买的股票"。输出的是**行业结构的认知**。
- 明确区分**结构性差异**（商业模式不同）与**经营差异**（同样的模式做得好坏）。
  把前者说成后者是行业分析最常见的错误。
- 财年不对齐、业务混合、会计口径差异都会造成假差异 —— 横切表末尾的
  「可比性检查」不是免责声明，是**必须逐条过一遍的清单**。
