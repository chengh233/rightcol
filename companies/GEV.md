## ⚠️ 最重要的一件事：现金不是从利润来的

| FY2025 | |
|---|---|
| 营收 | $38.1B |
| **营业利润** | **$1.4B（利润率仅 3.6%）** |
| 经营现金流 | **$5.0B** |
| **OCF / 营业利润** | **3.6×** |
| **非经营损益占税前** | **50.9%** |
| TTM FCF | **$12.4B** |

差额主要是**客户预付款**（大型设备订单先收钱）—— **和 neocloud 是同一个结构**：
现金来自订单增长，不是来自利润。**订单增速一放缓，OCF 先塌，而利润表上看不出来。**

对照 Vertiv 的 OCF/营业利润 = 1.0~1.2×，差别一目了然。

## 闸门 2 —— 两个口径差 5 倍，本身就是警告
